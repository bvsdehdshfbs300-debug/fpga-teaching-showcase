## 入门：电平与时间

| 练习 | 核心目标 |
| --- | --- |
| 点亮两颗灯 | 输出电平如何对应引脚和 LED |
| 让灯闪烁 | 用计数器分频，而不是把高速时钟直接当可见闪烁 |
| 按键消抖 | 区分触点抖动与稳定输入 |
| 流水灯 | 理解移位与时序更新 |
| 状态机：交通灯 | 划分状态、转换条件与输出 |
| PWM 呼吸灯 | 用占空比变化控制平均亮度 |

## 接口与显示

| 练习 | 核心目标 |
| --- | --- |
| 串口发送 | 起始位、数据位、停止位与位周期 |
| 串口回环 | 接收一帧，再组织发送 |
| I2C 写 EEPROM | 起停条件、串行数据与应答 |
| 视频时序与彩条 | 理解行、场、有效区与颜色数据 |
| 让方块走起来 | 帧内位置保持、帧间更新与边界回绕 |
| 把一张图显示出来 | 把坐标换算成表的行列与位索引 |

## 存储、模块协作与网络

| 练习 | 核心目标 |
| --- | --- |
| 同步 FIFO | 写读顺序、满空与使能 |
| 按键到 UART | 把消抖、触发与串口模块连起来 |
| ROM 查表 | 地址查表和寄存输出的延迟 |
| RAM 读写 | 同步访问与同址读写行为 |
| SPI 发送 SD 命令 | 时钟、片选、移位与命令格式 |
| 读取 SD 响应 | 发送后继续接收、对齐响应位 |
| 16 位反码校验和 | 累加、进位折叠、取反 |
| ARP 请求 | 按字段组织一个网络帧 |
| ICMP 应答 | 识别请求并构造对应回复 |
| UDP 回环 | 检查目标字段并返回收到的数据 |

## 高速数据流

| 练习 | 核心目标 |
| --- | --- |
| Ready/Valid 握手 | 明确哪一拍发生传输，停顿时保持数据 |
| Skid Buffer | 下游急停时接住暂存数据 |
| 双时钟异步 FIFO | 用格雷码指针和同步器协调两个时钟域 |
| 流式 CRC32 | 数据逐拍进入，校验状态逐拍更新 |

建议每关至少做一次“改一个条件再看波形”的实验。记住代码只是起点，能解释输出为什么在这一拍变化，才真正完成这一轮练习。

高速章聚焦数字逻辑层，不代表已经覆盖 PCIe、DDR 或 SerDes 的完整物理层实现。
