## 外设实验室 · 4.1 新增

五关分别设计，可以按兴趣进入；不用先通过 SPI 才能练 ADC 或 DAC。

| 练习 | 核心目标 |
| --- | --- |
| [L27 ADC：接住每一个采样点](https://dgwfpga.cn/practice/#/level/L27_adc_capture) | 有效拍采样、暂停保持、样本计数和峰值统计 |
| [L28 DAC：用数字码画出波形](https://dgwfpga.cn/practice/#/level/L28_dac_wave) | 数字波形生成、幅度裁减、更新时序与输出保持 |
| [L29 SPI：读出存储器的身份](https://dgwfpga.cn/practice/#/level/L29_spi_register) | 片选、串行移位、命令发送与 ID 读回 |
| [L30 GPIO：每一根线都有方向](https://dgwfpga.cn/practice/#/level/L30_gpio_bus) | 输入、输出和使能的关系，四路双向引脚与读回 |
| [L31 PCIe：让电脑读写板卡寄存器](https://dgwfpga.cn/practice/#/level/L31_pcie_bar) | BAR 地址解码、字节写使能、读完成响应、Tag 与反压 |

点击三维设备和接口，查阅对应手册；结合波形与外设观察台检查结果。ADA107 的逐针手册可查询 ADC/DAC 接线，单独选择某一针查看用途与关联接口。

建议每关至少做一次“改一个条件再看波形”的实验。记住代码只是起点，能解释输出为什么在这一拍变化，才真正完成这一轮练习。

高速章与外设章聚焦数字逻辑和事务处理，不代表已经覆盖 PCIe、DDR 或 SerDes 的完整物理层实现。
