# 常见问题

[返回介绍页](../README.md) · [新手指南](QUICKSTART.md)

## 平台收费吗？需要下载 GitHub 代码吗？

目前在线练习免费。打开 https://dgwfpga.cn/ 即可；本仓库是介绍与使用帮助，不提供主站源码，也无需下载后部署。

## 没有开发板能练吗？

可以。平台提供浏览器中的代码练习、运行结果、波形、3D 板卡和显示反馈。网页内的板卡是可交互教具，不是在远程给你的实体开发板烧录。

## 平台与真实开发板练习有什么关系？

这里适合练语法、电路行为、协议和时序分析。实际项目仍需要面对器件约束、时序收敛、板级电气条件和真机测试；通过关卡不等于已经完成硬件签核。

## 我的代码和进度存在账号里吗？

目前没有账号云同步。普通关卡的 Verilog 草稿、XDC、进度和波形设置主要存在当前浏览器本地。第一关是教程关，每次从引导开始，不按普通关卡的方式恢复草稿。

## 换电脑、换浏览器之后怎么继续？

先在原设备导出练习包，再在新设备的对应关卡导入。练习包包含代码与约束，不自动恢复所有通关状态。隐私模式、清除站点数据和更换访问域名也可能让原来的草稿不可见。

## 更新网页会清掉代码吗？

正常发布网页不应主动清除浏览器草稿。但浏览器清理、隐私模式、存储异常、换浏览器或换网址都会影响读取。重要练习请导出备份，不要只靠页面自动保存。

## 灯为什么还没亮？

先检查代码与 XDC 是否通过，再检查练习中的流程是否已完成。板卡 LED 在接线、下载交互后才按波形反馈；还要注意当前游标位置与 LED 的有效电平。有的时刻灯不亮，正是代码要求的结果。

## 密密麻麻的波形是不是显示坏了？

全局窗口可能包含数十万次跳变，有限像素无法逐个画出。先缩小时间范围，再使用游标与跳变定位；普通密集信号可打开局部精细窗口。活动带不能当作单个逻辑电平读取。

## 运行比较慢，怎么办？

显示类等关卡计算量较大，服务繁忙时也会排队。先等待当前请求完成，避免重复点击；相同提交可能命中缓存。若持续失败，请记录关卡、时间、运行编号、错误文字和网络情况再反馈。

## 新管理台是否意味着学员也需要注册？

站主管理台用于平台维护，有独立登录。学员仍然免注册练习，代码与进度继续保存在当前浏览器；它不等于账号云同步。

## 手机能用吗？

手机可以访问和查看页面。代码输入、图形连线和精细波形操作更适合电脑；具体流畅度取决于浏览器、设备和网络。
