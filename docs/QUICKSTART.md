# 第一次使用：从点亮两颗灯开始

[返回介绍页](../README.md) · [打开练习站](https://dgwfpga.cn/practice/) · [常见问题](FAQ.md)

你需要一台能打开现代浏览器的电脑和正常网络。无需先买开发板、注册账号或安装桌面 FPGA 开发工具。

## 先认识三个区域

| 区域 | 做什么 |
| --- | --- |
| 代码与约束 | 修改 Verilog，为需要物理引脚的关卡填写 XDC |
| 结果与波形 | 查看报错、判题和各信号随时间的变化 |
| 3D 板卡 | 观察灯和屏幕，点击元件查看对应手册 |

## 完成第一次练习

1. 进入选关页，打开“点亮两颗灯”。这一关会逐步介绍界面和操作。
2. 跟着引导阅读端口与代码，完成要求修改的内容。不要只看代码能否编译，也要理解输出电平与 LED 的关系。
3. 打开“约束”，按引导填写引脚。可以手写，也可以选择端口再选引脚，观察连线与文本的对应关系。
4. 点击绿色运行按钮，等待结果。失败时先读中文错误与标红位置，再看具体哪项检查未通过。
5. 查看波形。拖动黄色游标，对照左侧数值，弄清输出在什么时刻变化。
6. 按引导走完练习里的后续流程，观察 3D 板卡反馈，再点击 LED 或其他元件查看手册。

第一关每次进入都会重新引导。它用于认识界面；从普通关卡开始再使用自动草稿保存和进度继续。

## 独立练习时的顺序

先看目标与 Tips → 补代码 → 按本关要求写约束 → 运行 → 读错误/判题 → 看波形 → 修改后再运行。

并非每一关都需要 XDC。纯片内数据通路课程可能不要求绑定物理引脚，以关卡提示为准。

## 常用操作

- 代码、控制台、资源与判题标题栏的放大按钮可以打开更宽敞的卡片；看完再收回。
- 波形可放大、平移、适配；两根游标可读取时间差。密集活动带表示当前窗口中变化太多，不表示信号静止。
- 普通信号看不清时使用“查看细节”，读取更小时间窗口的真实边沿。
- 在 3D 板卡上点击元件可查看手册；点击显示屏可打开大屏窗口。
- 4.1 硬件桌面底部有八个视角，可快速找到 AD/DA、SPI、GPIO、PCIe、仪器与接口。
- 手册可搜索元件和引脚，目录上下滚动；点针号查看用途，再通过关联按钮跳到另一端接头。
- 代码编辑区有导入/导出入口，可保存练习包，把当前代码与 XDC 带走。

## 离开前保存

普通关卡的草稿和进度主要保存在当前浏览器。换设备前先导出练习包，建议同时在自己电脑上保留一份。

在另一设备使用同一网站，进入对应关卡后导入练习包。它用于恢复代码和约束，不等于完整迁移所有通关记录。
